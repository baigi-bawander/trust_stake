# IDL

`truststake.json` in this directory is TrustStake's Anchor IDL, generated by `anchor build`
(it lands at `target/idl/truststake.json`, which is gitignored — this is a committed copy of
that output).

It matches the binary deployed to devnet on 2026-08-31, program ID
`3Vc6M8Az9h2GtDmqqhQKURqTKKygNfekQq7PoJris6V2`, SHA-256
`101a10d8145870f77a2b79f66d41c8af85252a6678a21083fcf4316551369bfc` (see CLAUDE.md's "Current
state" for how that was verified).

**Regenerate and re-commit this file after any future deploy that changes program logic.**
This is exactly the kind of file that goes stale silently — nothing breaks visibly when it
drifts from the deployed binary, it just quietly mis-describes instructions or mis-numbers
error codes for anyone building against it. Run `anchor build`, then `cp
target/idl/truststake.json idl/truststake.json`.

The onchain-published IDL (fetched via `anchor idl fetch`) is a separate copy with its own
history — see CLAUDE.md's IDL entry under "Working in this repo" for its current state and
why it's still the 2026-08-24 version. This file is unaffected by that and is the one to trust
for local development.
